# ALANA ELECTRONICS Easy 8 · Guía de pinout

Guía del conector de 56 pines de la ECU Alana Easy 8 v1.0: tabla de pines con buscador y filtros por familia, función de cada pin, cableado de la sonda lambda, alimentación y masas, y puntos a comprobar antes de cablear.

Web: https://gunter443.github.io/alana-easy8/

La página es un solo archivo, `index.html`, sin dependencias que instalar. Para cambiarla, edita ese archivo y súbelo de nuevo; GitHub Pages publica la nueva versión en uno o dos minutos.

Guía independiente, no es la web oficial de Alana Electronics. Los datos están tomados del manual de uso de la ECU Alana Easy 8 v1.0. Comprueba siempre el conexionado antes de alimentar la ECU.
